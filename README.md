# Portfolio

Source for [zyledoctolero.vercel.app](https://zyledoctolero.vercel.app). React 19, Vite, Tailwind CSS v4 and Framer Motion.

Editorial layout: warm paper, large type, one accent colour, and motion that only shows where things come from.

## Run it

```bash
npm install
npm run dev
```

Content lives in `src/data/`. Components live in `src/components/ui/`.
